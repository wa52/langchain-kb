Source: MVTec HALCON Operator Reference, lines_facet
URL: https://www.mvtec.com/doc/halcon/2411/en/lines_facet.html

The operator extracts line and curvilinear structures from an image. Its output parameter Lines consists of subpixel-precise XLD contours. The LightDark parameter specifies whether bright or dark lines are extracted; the documented values include `light` and `dark`.

This reference excerpt does not state that every result must be a geometrically straight line. Do not infer unrelated parameter semantics from the example call.
