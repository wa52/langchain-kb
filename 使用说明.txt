# 个人知识库 安装使用说明

你拿到了一个安装包文件：`personal_knowledge_base-1.0.0-py3-none-any.whl`。按下面步骤即可安装使用。

## 一、环境要求

- Windows 系统
- Python 3.10 或更高版本（3.10/3.11/3.12/3.13 均可）
- 需要能联网（安装依赖、下载模型、调用 DeepSeek API 都要网络）

## 二、安装（推荐：虚拟环境）

打开 PowerShell，按顺序执行：

```powershell
# 1. 进入存放 whl 的文件夹
cd 你的whl所在目录

# 2. 创建虚拟环境（会下载并安装 torch 等依赖，需要几分钟）
python -m venv kb_env

# 3. 激活环境
kb_env\Scripts\activate

# 4. 安装
pip install personal_knowledge_base-1.0.0-py3-none-any.whl

# 5. 验证
knowledge --help
```

看到命令列表就安装成功了。

> 不想建虚拟环境也可以，直接执行第 4 步即可（全局安装）。

## 三、配置 DeepSeek API Key（必做，否则问答不可用）

首次运行问答类命令（如 `knowledge chat`、`knowledge web`）时，如果还没配置 API Key，会提示你输入，输入后自动保存。也可以手动创建配置文件：

在**你想存放数据的位置**建一个文件夹（比如 `D:\KnowledgeBase`），在里面建一个 `.env` 文件，内容：

```ini
DEEPSEEK_API_KEY=你的key
DEEPSEEK_API_BASE=https://api.deepseek.com
HF_ENDPOINT=https://huggingface.co
EMBEDDING_MODEL=bge-small-zh
LLM_MODEL=deepseek-chat
```

DeepSeek API Key 在 https://platform.deepseek.com 注册获取。

## 四、怎么用

每次打开 PowerShell 后（若用了虚拟环境，先 `kb_env\Scripts\activate`）：

### 1. 设置数据目录（推荐）

告诉程序数据存在哪。在数据目录（含 .env 的文件夹）下运行即可——程序会把数据自动建在当前目录：

```powershell
# 先进入你的数据目录
cd D:\KnowledgeBase
```

### 2. 添加资料

两种方式任选其一：

**方式 1：命令行直接添加**
```powershell
knowledge index D:\你的文档路径
```

**方式 2：控制台内添加**（先 `knowledge cli` 进入交互界面，再输入）
```
/add D:\你的文档路径
```

**支持的文件格式：**
- 文档：`.md` `.txt` `.pdf`
- HALCON 例程：`.hdev`（自动解析算子调用链和注释）
- 源代码：`.c` `.cpp` `.cs` `.vb` `.py` `.h`（自动提取函数、注释和 API 调用）
- 图片（`.png` `.jpg` `.tif` 等）自动跳过，不会进入知识库

> 两者功能相同，都是把资料复制到知识库的数据目录并建立索引。

### 3. 问答

```powershell
knowledge chat "你的问题"          # 单次问答，基于知识库回答
knowledge chat                     # 直接运行（不带问题）→ 进入交互式多轮对话
knowledge chat --session 会话ID    # 恢复之前的会话继续聊
```

> 交互式对话中：输入 `exit` 退出，`clear` 清除历史，退出时自动保存会话。

### 4. 其他常用命令

```powershell
knowledge search "关键词"          # 只搜索，不问答
knowledge status                   # 查看状态
knowledge doctor                   # 健康检查
knowledge web                      # 启动网页版聊天界面（浏览器访问 http://127.0.0.1:8000）
knowledge cli                      # 交互式命令行聊天（同 knowledge chat 不带参数）
```

## 五、常见问题

| 问题 | 解决 |
|------|------|
| `knowledge` 不是内部命令 | 没安装成功，或没激活虚拟环境。重装 whl |
| 首次运行下载模型卡住 | 正常，首次要下载约 33MB 的嵌入模型，等它完成 |
| 问答报错 "API Key" | 检查 .env 里的 DEEPSEEK_API_KEY 是否正确 |
| 路径含中文报错 | 在 .env 里加一行 `CHROMA_PERSIST_DIR=D:/你的ASCII路径/chroma_db` |

## 六、关于已有数据（重要）

安装后程序会自动创建 `chroma_db`（向量库）和 `data` 目录，但**里面是空的**——whl 只含程序，不含任何文档数据。

对方需要二选一：

**方式 1：导入自己的资料**
```powershell
knowledge index D:\你的文档路径     # 支持 .md/.txt/.pdf 文件或文件夹
```

**方式 2：直接使用你现有的知识库**
把以下目录一起复制到对方电脑（放到数据目录下）：
```
chroma_db\      ← 你已导入的向量数据
data\           ← 源文档、外置数据、会话历史
```
再进入该目录运行，即可直接使用你现有的知识库，无需重新导入。

> 注意：`chroma_db` 和 `data` 不包含在 whl 安装包里，必须手动复制。
