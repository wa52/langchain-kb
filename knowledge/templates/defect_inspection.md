# 缺陷检测项目方案模板

## 项目类型
缺陷检测（defect inspection）

## 必须章节
1. 项目背景
2. 检测目标
3. 技术指标
4. 成像方案
5. 定位方案
6. 视觉流程
7. 算法方案
8. 软件架构
9. 风险分析
10. 验收标准

## 每章节说明
- **项目背景**：产品类型、产线位置、检测目的
- **检测目标**：缺陷类型（划痕/异物/缺件/污渍），缺陷最小尺寸
- **技术指标**：检测精度、误判率、漏检率、节拍、良率
- **成像方案**：相机分辨率、镜头焦距、光源类型（明场/暗场/背光）、打光角度
- **定位方案**：工件定位方式（模板匹配/机械定位/视觉引导）
- **视觉流程**：采图 → 预处理 → 缺陷分割 → 特征提取 → 判定
- **算法方案**：Blob分析/分割/形态学/深度学习异常检测
- **软件架构**：SDK、相机驱动、PLC 通讯、界面、数据存储
- **风险分析**：光照波动、来料一致性、误判风险、节拍压力
- **验收标准**：检测率、误判率、稳定运行时长、节拍达成

## 输出要求
- 每章节给出具体可执行要点，引用知识库来源 [来源: 文件名]
- 技术指标尽量量化，未明确的标为待确认

## 验收检查点
- 含检测目标分析 ✓
- 含相机/光源选型思路 ✓
- 含定位方案 ✓
- 含算法方案 ✓
- 含软件流程 ✓
- 含风险点 ✓
- 含待人工确认问题 ✓
